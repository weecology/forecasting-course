## How to Contribute

* The course website is built with [Quarto](https://quarto.org/)
* Most content is stored in one folder per lesson in the [`lessons` folder](https://github.com/weecology/forecasting-course/tree/main/lessons)
* To add a new lesson make a copy of the [lesson template folder](https://github.com/weecology/forecasting-course/tree/main/lessons/LessonTemplate), edit the pages in the resulting folder using [markdown](https://www.markdownguide.org/), and add the lesson to the `sidebar` section of `_quarto.yml`
* Contributions of new lessons are welcome as Pull Requests or we can work with you to add new material and data to the site
* If you want to create a modified copy of the course including the website you should fork or copy the repository and [connect it to Netlify](https://docs.netlify.com/welcome/add-new-site/) to automatically build the site

## Reporting Issues or Problems

* To report issues or problems with either the material or the operation of the site please [open an issue](https://github.com/weecology/forecasting-course/issues/new) and we'll be happy to address it.

## Support

* [Open an issue](https://github.com/weecology/forecasting-course/issues/new) if there’s anything we can do to help!
